## Question

The motivating question, why it matters, the intended reader and use, and the existing work it builds on: pending.

## Scope

Exact definitions, quantifiers, the setting (for instance the base field or ring, the category, the space or the class of objects), hypotheses, the included and excluded cases, and any ambiguity that changes the answer: pending.

## Accepted inputs

Background results accepted without re-proof, each with its exact source, edition and evidence state, and the premises still unresolved: none recorded. An input whose source has not been checked is an open premise, and every conclusion that depends on it says so. ("Classical; no source checked" in the [citation-check skill](../.agents/skills/citation-check/SKILL.md) is only for results the project proves itself.) Reported peer review of earlier work is provenance; it is not this project's verification.

## Confusable notions

Pairs that this subject makes easy to conflate, which every statement must keep apart. Typical kinds: for all $n$ versus for infinitely many $n$; pointwise versus uniform; bounded versus uniformly bounded; injective versus surjective; existence over a field versus over its algebraic closure; a property of each member of a family versus of the family. Write the project's own list: pending.
